# 式の中に隠れているもの

展開・因数分解・式変形が「単調な作業」に見えてしまう時期に、**5分で意味を取り戻す**ための授業用スライドです。中学3年向け。

**▶ https://kouju.github.io/math-is-so-cool/**

ブラウザで開くだけ。ビルド不要、依存パッケージなし（`index.html` 1枚）。

---

## ねらい

| 数学の操作 | その本質 |
| --- | --- |
| 展開 | まとまった構造をばらして調べる |
| 因数分解 | バラバラの情報から構造を見つける |
| 式変形 | 同じものを別の視点から眺める |

この3つを一本の線でつなぎ、「なぜ `y = 0` になる `x` を知りたいのか」を実例で見せます。

## 構成（全8枚・約5分）

| # | 画面 | 内容 | 目安 |
| --- | --- | --- | --- |
| 1 | 問い | `y = x² − 7x + 10` を見せて「何がわかる?」と聞く | 20秒 |
| 2 | 三つの情報 | **同じ式・同じグラフ**のまま、展開形 / 因数分解形 / 対称性 を切り替える（山場） | 60秒 |
| 3 | 三つの本質 | 上の表 | 30秒 |
| 4 | ① 力学 | `5t(4−t) = 0` → ボールは4秒で落ちる。ボールが飛ぶアニメつき | 50秒 |
| 5 | ② 情報通信 | `1 − (f/13.56)² = 0` → ICカードが反応する周波数。共振のアニメつき | 40秒 |
| 6 | ③ インフラ | `6 − 0.06x² = 0` → トンネルの幅。トラックを動かすと端で天井に当たる | 40秒 |
| 7 | ④ 経済 | `2(40+x)(100−x) = 0` → 赤字と黒字の境界。最適価格は130円 | 50秒 |
| 8 | 締め | 今日使った道具は2つだけ | 30秒 |

4つの実例はすべて操作できます。

## 使った道具は2つだけ

- `(x − a)(x − b) = 0` … ボールの落下時刻／パン屋の黒字の両端。**2つの解の真ん中が頂点**。
- `a² − b² = (a − b)(a + b)` … ICカードの共振周波数／トンネルの幅。

④ボールの最高点（2秒）と⑦パン屋の最適価格（30円）が同じ理屈で出るところが、話の山になります。

## 操作

- `←` `→` キー、または画面下のボタンで進む
- `1`〜`8` キーで直接ジャンプ
- 右上 **全画面** … 投影用
- 右上 **指導メモ** … 各画面の話し方の目安と秒数（投影時はオフのまま）
- 配色は端末のライト / ダーク設定に追従。スマホでも縦に積まれて読めます

## 中学3年の範囲に合わせてあります

意図的に外したもの:

- **平方完成** … 頂点は「放物線は左右対称だから、2つのゼロ点の真ん中」で出します。その `x` を因数分解形に入れ直せば `y` も出るので、新しい公式はいりません。
- **不等式** … 「通れる範囲」は不等式を解かず、境界の値として扱っています。

グラフは見せるだけで、描かせる必要はありません（中3で扱うのは `y = ax²` まで）。

高校1年（数I）で使う場合は、画面2に平方完成形を1枚足すと、3つの顔がそろいます。

## 技術メモ

- `index.html` 単体。外部依存は Google Fonts（Zen Kaku Gothic New / STIX Two Text）のみで、読み込めない環境でもフォールバックして動きます
- グラフ・アニメーションはすべて手書きの inline SVG + `requestAnimationFrame`。図形ライブラリは不使用
- `prefers-reduced-motion` に対応（アニメーションを止めて静止状態で表示）
